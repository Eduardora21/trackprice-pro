# 🚀 TrackPrice Pro

Monitor ligero de precios de vuelos, envíos y productos web en tiempo real. Este proyecto está diseñado para extraer información de precios mediante scraping web/APIs, almacenar el historial de datos y visualizarlos en una interfaz moderna.

---

## 🛠️ Stack Tecnológico

* **Backend:** Node.js, Express.js
* **Scraping:** Axios, Cheerio
* **Proxy Inverso:** Nginx
* **Contenedorización:** Docker, Docker Compose
